🎓 Smart AI Academic Intelligence System

An advanced AI-powered Academic Intelligence and Management Platform built using the MERN Stack (MongoDB, Express.js, React.js, Node.js) and Python Machine Learning models.
The system combines predictive analytics with academic administration automation to help educational institutions improve student success rates, reduce dropout risks, and streamline daily academic operations.

🛠️ Tech Stack
🎨 Frontend
Core Framework: React.js (Vite Workflow)
Styling Framework: Tailwind CSS (@tailwindcss/postcss)
State Management & Navigation:
React Router DOM
React Context API
Authentication Context
Theme Context
Toast/Notification Context
API Communication: Axios (Centralized Modular Instance)
⚙️ Backend
Runtime Environment: Node.js
Framework: Express.js
Database: MongoDB
ODM: Mongoose
Security & Authentication:
JSON Web Tokens (JWT)
Bcrypt.js
Scheduling & Automation: Node-cron
File Processing:
Multer (Multipart File Uploads)
ExcelJS (Spreadsheet Processing)
Email Services: Nodemailer
🤖 Machine Learning Layer
Language: Python 3.13
Libraries & Frameworks:
Scikit-Learn
Pandas
NumPy
Model Serialization: Pickle (.pkl)
Express ↔ Python Communication: python-shell
Synchronous Execution
Asynchronous Execution
🧱 Project Architecture & Workflow

The Smart AI Academic Intelligence System follows a Decoupled Client–Server–ML Engine Architecture, enabling scalability, maintainability, and efficient processing of academic data.
